# v0.6.0 — Foundation + Home + Now Playing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the oto Flutter UI foundation (theming, the source-model state layer, an adaptive shell, local prefs) plus the Home and Now Playing screens, on the existing Rust/FRB capability layer.

**Architecture:** A keep-alive `householdNotifierProvider` accumulates per-room/per-group state from `discoveryProvider` (identity skeleton) + `changeEventsProvider` (live deltas); a pure `sourcesFromHousehold` selector derives the active sources. Commands apply optimistic, LAN-throttled updates and reconcile from events. The UI is a faithful translation of the committed design system (`docs/design-system/`), bound to those providers.

**Tech Stack:** Flutter, Riverpod 3 (codegen), flutter_rust_bridge 2.12.0, shared_preferences, flutter_svg, lucide_icons. Source spec: [`docs/superpowers/specs/2026-06-09-v0.6.0-foundation-home-nowplaying-design.md`](../specs/2026-06-09-v0.6.0-foundation-home-nowplaying-design.md).

## Conventions for this plan

- **The design system is the pixel-authoritative source.** Widget tasks reference the committed React prototype (`docs/design-system/hifi-unified.jsx`, by `V3*` component + line range) and `docs/design-system/handoff/design-tokens.json` for exact layout/spacing/colors. This plan specifies the Flutter **structure, state bindings, and tests** — it does not re-transcribe every style literal. Translate faithfully; pull every numeric/color from `tokens.dart` (Task 1), never hard-code.
- **Codegen:** after editing any `@riverpod` provider run `just gen` (or `cd app && dart run build_runner build --delete-conflicting-outputs`) to regenerate `*.g.dart`, then commit the generated file with its source. `freezed`/`riverpod_generator` are already configured.
- **Gates:** every task ends green on `cd app && flutter analyze` + the task's `flutter test`. The final task also runs `just check` + the integration test. Per [AGENTS.md §6], a touch to `native/**` would require `just check` + `just test`; **this milestone is Dart-only** (no `native/` edits), so the Rust gates are not triggered — call that out if a task ever needs an `api.rs` change (it should not).
- **File state model:** all state lives in `app/lib/src/`. Pure Dart (models, reducers, selectors, position math, throttle) has **no Flutter import** so it unit-tests without a binding.

List<Source> sourcesFromHousehold(Household h) {
  final out = <Source>[];
  for (final g in h.groups.values) {
    if (!g.hasActiveStream) continue;
    final names = g.memberIds.map((id) => h.rooms[id]?.name ?? id).toList();
    out.add(Source(id: g.id, label: names.join(' + '), track: g.track, memberCount: g.memberIds.length));

  out.sort((a, b) => a.label.compareTo(b.label));
  return out;
}

@Riverpod(keepAlive: true)
class HouseholdNotifier extends _$HouseholdNotifier {
  @override
  Household build() {
    ref.listen(discoveryProvider, (_, next) {
      next.whenData((topo) => state = householdFromTopology(topo, previous: state));
    }, fireImmediately: true);
    ref.listen(changeEventsProvider, (_, next) {
      next.whenData((e) => state = applyEvent(state, e));
    });
    return const Household();
  }

  // Optimistic mutators used by Task 4.
  void setOptimisticVolume(String speakerId, int v) =>
      state = applyEvent(state, ChangeEventDto.volume(speakerId: speakerId, volume: v));
  void setOptimisticMuted(String speakerId, bool m) =>
      state = applyEvent(state, ChangeEventDto.mute(speakerId: speakerId, muted: m));
  void setOptimisticGroupVolume(String groupId, int v) =>
      state = applyEvent(state, ChangeEventDto.groupVolume(groupId: groupId, volume: v));
  void setOptimisticTransport(String groupId, PlaybackState t) =>
      state = applyEvent(state, ChangeEventDto.playback(groupId: groupId, state: _toDto(t)));
}

```dart
import 'dart:async';

/// Trailing throttle: at most one [run] action fires per [window]; a burst
/// collapses to the latest. [flush] fires the pending action now.
class Throttle {
  Throttle(this.window);
  final Duration window;
  Timer? _timer;
  void Function()? _pending;

  void run(void Function() action) {
    _pending = action;
    _timer ??= Timer(window, _fire);
  }

  void flush() {
    _timer?.cancel();
    _timer = null;
    _fire();
  }

  void _fire() {
    final p = _pending;
    _pending = null;
    _timer = null;
    p?.call();
  }

  void dispose() => _timer?.cancel();
}
```

```dart
class PlaybackController {
  PlaybackController(this.ref, this.api);
  final Ref ref;
  final CommandApi api;
  final _volThrottle = <String, Throttle>{};

  Future<void> togglePlay(String groupId, PlaybackState current) async {
    final next = current == PlaybackState.playing ? PlaybackState.paused : PlaybackState.playing;
    final h = ref.read(householdNotifierProvider.notifier)..setOptimisticTransport(groupId, next);
    try {
      next == PlaybackState.playing ? await api.play(groupId) : await api.pause(groupId);
    } on CommandError catch (e) {
      _onError(e, rollback: () => h.setOptimisticTransport(groupId, current));
    }
  }

  void setVolume(String speakerId, int v) {
    ref.read(householdNotifierProvider.notifier).setOptimisticVolume(speakerId, v);
    _volThrottle.putIfAbsent(speakerId, () => Throttle(const Duration(milliseconds: 150)))
        .run(() => _send(() => api.setVolume(speakerId, v)));
  }

  void setVolumeEnd(String speakerId, int v) {
    ref.read(householdNotifierProvider.notifier).setOptimisticVolume(speakerId, v);
    _volThrottle[speakerId]?.flush();
    _send(() => api.setVolume(speakerId, v));
  }

  Future<void> _send(Future<void> Function() op) async {
    try { await op(); } on CommandError catch (e) { _onError(e); }
  }

  void _onError(CommandError e, {void Function()? rollback}) {
    if (e is CommandError_NotFound) {
      ref.invalidate(discoveryProvider); // stale GroupId → re-discover (sonos-notes § Identifiers)
    } else {
      rollback?.call();
    }
    // else: optimistic value stands; a no-op set emits no echo (sonos-notes § Group ops).
  }
}
```
