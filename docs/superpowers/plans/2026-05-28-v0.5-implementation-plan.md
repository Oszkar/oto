# v0.5 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close v0.4 carryovers (topology events, SubscriptionError, lock revisit), the v0.3 `model` debt, and the Android release-discovery blocker — leaving v0.6 a pure UI problem.

**Architecture:** Three Phase 0 prereq PRs (Android smoke, path revisit, ZGT probe) gate Phase 1's five slice PRs. Topology events ride the existing v0.4 FRB change-event stream as a payload-less `TopologyChanged` notification + a `refresh_topology()` fast-path that re-pulls authoritative topology via `GetZoneGroupState` SOAP (skipping SSDP). `SubscriptionError`/`Recovered` emit reactively from `oto-app` on command-dispatch failure transitions. Android `MulticastLock` lives in Kotlin behind a `MethodChannel`, wrapped around `discover()` on the Dart side. `model` populates from `device_description.xml` via parallel `ureq` fetches inside `discover()`. Lock-granularity revisit is observation-only by default.

**Tech Stack:** Rust 1.94 + `sonos-api =0.5.2` + `sonos-sdk-{state,event-manager,stream,callback-server} =0.5.2` + `quick-xml =0.31.0` + `ureq` (transitive) for SOAP/HTTP. Flutter 3.38 + Riverpod 3 (codegen) + FRB 2.12.0. Kotlin for the Android `WifiManager.MulticastLock` platform channel handler.

**Spec:** [`docs/superpowers/specs/2026-05-28-v0.5-design.md`](../specs/2026-05-28-v0.5-design.md).

fn subscribe_topology(&self) -> Result<(), WireError> {
    let mut model = self.state.lock().unwrap_or_else(|p| p.into_inner());
    if !self.discovered.load(Ordering::Acquire) {
        return Err(WireError::NoSpeakersDiscovered);
    }
    if model.topology_subscribed {
        return Err(WireError::AlreadySubscribed);
    }
    model.topology_subscribed = true;
    Ok(())
}

fn refresh_topology(&self) -> Result<DiscoverySnapshot, WireError> {
    let mut model = self.state.lock().unwrap_or_else(|p| p.into_inner());
    if let Some(outcome) = model.next_refresh.take() {
        return outcome;
    }
    if !self.discovered.load(Ordering::Acquire) {
        return Err(WireError::NoSpeakersDiscovered);
    }
    // Default: return the original outcome (same as discover()'s snapshot).
    self.outcome.clone()
}
```

fn subscribe_topology(&self) -> Result<(), WireError> {
    let mut state = self.state.lock().unwrap_or_else(|p| p.into_inner());
    if state.id_to_addr.is_empty() {
        return Err(WireError::NoSpeakersDiscovered);
    }
    if state.topology_subscribed {
        return Err(WireError::AlreadySubscribed);
    }
    if state.pump.is_some() {
        // Pump already spawned (subscribe_speakers ran first) — for v0.5 we
        // tighten the contract: subscribe_topology must come before
        // subscribe_speakers. Tasks 5+oto-app will call them in that order.
        return Err(WireError::AlreadySubscribed);  // close-enough error reuse
    }
    state.topology_subscribed = true;
    Ok(())
}

fn refresh_topology(&self) -> Result<DiscoverySnapshot, WireError> {
    let cached_ip = {
        let state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        state.id_to_addr.values().copied().next()
    }.ok_or(WireError::NoSpeakersDiscovered)?;

    let client = sonos_api::SonosClient::new();
    let op = sonos_api::services::zone_group_topology::get_zone_group_state().build();
    let resp = client
        .execute_enhanced(&cached_ip, op)
        .map_err(|e| WireError::Network(e.to_string()))?;
    let infos = sonos_api::services::zone_group_topology::parse_zone_group_state_xml(
        &resp.zone_group_state,
    ).map_err(|e| WireError::Backend(e.to_string()))?;

    // Build the snapshot via existing adapter (re-use to_snapshot or factor out).
    let snapshot = adapter::to_snapshot(&infos)?;

    // Update interior caches (write lock).

/// v0.5 — topology change controller. Listens on the unified
/// changeEventsProvider for TopologyChanged events, debounces a
/// 250 ms window, then calls refreshTopology() and invalidates the
/// discoveryProvider so consumers re-render against fresh topology.
library;

import 'dart:async';
import 'package:riverpod_annotation/riverpod_annotation.dart';

import '../rust/api.dart' as rust_api;
import 'discovery.dart';
import 'events.dart';

part 'topology.g.dart';

@Riverpod(keepAlive: true)
class TopologyController extends _$TopologyController {
  Timer? _debounce;

  @override
  void build() {
    final eventsAsync = ref.watch(changeEventsProvider);
    final sub = eventsAsync.whenData((event) {
      if (event is rust_api.ChangeEventDto_TopologyChanged) {
        _scheduleRefresh();
      }
    });

    ref.onDispose(() {
      _debounce?.cancel();
    });
  }

  void _scheduleRefresh() {
    _debounce?.cancel();
    _debounce = Timer(const Duration(milliseconds: 250), () async {
      try {
        await rust_api.refreshTopology();
        ref.invalidate(discoveryProvider);
      } catch (e) {
        // Refresh failed — caches unchanged on Rust side; UI keeps last
        // known. Next TopologyChanged or manual discover() retries.
      }
    });
  }
}
```

use std::{collections::HashMap, sync::RwLock};

use oto_core::{ChangeEvent, SpeakerId, WireError};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum HealthState {
    Healthy,
    Errored,
}

pub(crate) struct HealthTracker {
    states: RwLock<HashMap<SpeakerId, HealthState>>,
}

impl HealthTracker {
    pub(crate) fn new() -> Self {
        Self { states: RwLock::new(HashMap::new()) }
    }

    pub(crate) fn reset_all(&self) {
        self.states.write().unwrap_or_else(|p| p.into_inner()).clear();
    }

    /// Apply a command result to `speaker`. Returns an event to emit (or None
    /// if no transition).
    pub(crate) fn observe<R>(
        &self,
        speaker: &SpeakerId,
        result: &Result<R, WireError>,
    ) -> Option<ChangeEvent> {
        let mut states = self.states.write().unwrap_or_else(|p| p.into_inner());
        let cur = states.get(speaker).copied().unwrap_or(HealthState::Healthy);
        match (cur, result) {
            (HealthState::Healthy, Err(WireError::Network(msg))) => {
                states.insert(speaker.clone(), HealthState::Errored);
                Some(ChangeEvent::SubscriptionError {
                    speaker: speaker.clone(),
                    message: msg.clone(),
                })
            }
            (HealthState::Errored, Ok(_)) => {
                states.insert(speaker.clone(), HealthState::Healthy);
                Some(ChangeEvent::SubscriptionRecovered { speaker: speaker.clone() })
            }
            _ => None,
        }
    }
}

```rust
use std::sync::{Mutex, OnceLock, mpsc::{self, Receiver, Sender}};
use oto_core::ChangeEvent;

struct Bus {
    tx: Sender<ChangeEvent>,
    rx: Mutex<Option<Receiver<ChangeEvent>>>,
}

static BUS: OnceLock<Bus> = OnceLock::new();

fn bus() -> &'static Bus {
    BUS.get_or_init(|| {
        let (tx, rx) = mpsc::channel();
        Bus { tx, rx: Mutex::new(Some(rx)) }
    })
}

pub fn sender() -> Sender<ChangeEvent> {
    bus().tx.clone()
}

pub fn take_receiver() -> Option<Receiver<ChangeEvent>> {
    bus().rx.lock().unwrap_or_else(|p| p.into_inner()).take()
}

pub(crate) fn push(event: ChangeEvent) {
    let _ = bus().tx.send(event);  // swallow if consumer dropped
}
```

**Scope note (d1):** this `AppEventBus` carries ONLY `oto-app`-originated events (SubscriptionError/Recovered). It is **not** the wire's channel and the wire's pump must **not** write to it — the wire keeps its own v0.4 `mpsc` channel and its drop-closes-the-stream behaviour unchanged. The bus's `rx` is re-taken by the FRB consumer when it rebuilds against a new wire; the bus `tx` lives in `oto-app` (which outlives any single wire), so app-side emissions survive wire replacement without affecting the wire-channel teardown signal.

The FRB consumer drains the two receivers with a short-timeout poll (no extra crate — std `mpsc`):

No new crate: a `crossbeam-channel` `select!` was considered and rejected (avoid the dependency). Use std `mpsc` — a helper that `recv_timeout`s the wire channel then `try_recv`s the app channel. Cost: ~10 ms latency on the no-events path. Acceptable (events are user-paced, not latency-critical).

class MulticastLockHandler(context: Context) : MethodChannel.MethodCallHandler {
    private val wifiManager = context.applicationContext
        .getSystemService(Context.WIFI_SERVICE) as WifiManager
    private var lock: WifiManager.MulticastLock? = null

    override fun onMethodCall(call: MethodCall, result: MethodChannel.Result) {
        when (call.method) {
            "acquire" -> {
                if (lock == null) {
                    lock = wifiManager.createMulticastLock("oto-ssdp").apply {
                        setReferenceCounted(true)
                    }
                }
                lock?.acquire()
                result.success(null)
            }
            "release" -> {
                lock?.release()
                result.success(null)
            }
            else -> result.notImplemented()
        }
    }
}

//! Fetch + parse Sonos device_description.xml for the `model` field.
//! Per sonos-notes § SSDP discovery § HTTP fetch quirk: use `ureq`
//! (already a locked transitive dep via `sonos-api`) — it handles
//! chunked transfer encoding. Raw TcpStream breaks.

use std::{net::IpAddr, time::Duration};

use quick_xml::events::Event;
use quick_xml::Reader;

const CONNECT_TIMEOUT: Duration = Duration::from_secs(1);
const READ_TIMEOUT: Duration = Duration::from_secs(2);

/// Fetch device_description.xml and extract `<modelName>`. Returns
/// `None` on any error (timeout, network, parse) — caller treats this
/// as "model unknown for this speaker", discovery does not fail.
pub(crate) fn fetch_model(ip: IpAddr) -> Option<String> {
    let url = format!("http://{ip}:1400/xml/device_description.xml");
    let agent = ureq::AgentBuilder::new()
        .timeout_connect(CONNECT_TIMEOUT)
        .timeout(READ_TIMEOUT)
        .build();
    let body = agent.get(&url).call().ok()?.into_string().ok()?;
    parse_model_name(&body)
}

fn parse_model_name(xml: &str) -> Option<String> {
    let mut reader = Reader::from_str(xml);
    reader.trim_text(true);
    let mut buf = Vec::new();
    let mut in_model = false;
    loop {
        match reader.read_event_into(&mut buf) {
            Ok(Event::Start(e)) if e.name().as_ref() == b"modelName" => {
                in_model = true;
            }
            Ok(Event::Text(t)) if in_model => {
                return Some(t.unescape().ok()?.into_owned());
            }
            Ok(Event::End(e)) if e.name().as_ref() == b"modelName" => {
                in_model = false;
            }
            Ok(Event::Eof) => return None,
            Err(_) => return None,
            _ => {}
        }
        buf.clear();
    }
}

/// Fetch `<modelName>` for each `(speaker_id, ip)` in parallel.
/// Returns a `HashMap<SpeakerId, String>` of populated models.
/// Speakers whose fetch fails are absent from the map.
pub(crate) fn fetch_models_parallel(
    targets: &[(oto_core::SpeakerId, IpAddr)],
) -> std::collections::HashMap<oto_core::SpeakerId, String> {
    use std::sync::{Arc, Mutex};
    use std::thread;

    let results: Arc<Mutex<std::collections::HashMap<oto_core::SpeakerId, String>>> =
        Arc::new(Mutex::new(std::collections::HashMap::new()));
    let handles: Vec<_> = targets
        .iter()
        .cloned()
        .map(|(sid, ip)| {
            let results = Arc::clone(&results);
            thread::spawn(move || {
                if let Some(model) = fetch_model(ip) {
                    results
                        .lock()
                        .unwrap_or_else(|p| p.into_inner())
                        .insert(sid, model);
                }
            })
        })
        .collect();
    for h in handles {
        let _ = h.join();
    }
    Arc::try_unwrap(results)
        .unwrap_or_else(|arc| Mutex::new(arc.lock().unwrap_or_else(|p| p.into_inner()).clone()))
        .into_inner()
        .unwrap_or_else(|p| p.into_inner())
}
