# Android debug smoke

Historical run: 2026-05-30, SDK 0.5.2, Flutter 3.44.0, Rust 1.94.0. Built in WSL2 and run on a Pixel 7a with Android 16 (API 36). This closed the Android deferral from [v0.4 acceptance](v0.4-release/README.md); it is not the current build guide.

`just build-apk` produced a debug APK containing arm64 and x86_64 Rust libraries. A temporary discovery/event harness installed and launched successfully, discovered two speakers in two groups, and received volume, mute, playback, and track events through FRB.

Representative console output:

```text
I/flutter : oto-P0a discovered 2 speakers / 2 groups
I/flutter : oto-P0a ChangeEvent: ChangeEventDto.volume(speakerId: RINCON_542A1B9463A801400, volume: 26)
I/flutter : oto-P0a ChangeEvent: ChangeEventDto.mute(speakerId: RINCON_542A1B9463A801400, muted: false)
I/flutter : oto-P0a ChangeEvent: ChangeEventDto.playback(groupId: RINCON_542A1B9463A801400:3426502567, state: PlaybackStateDto.playing)
```

Discovery worked in this debug session without a multicast lock. The reason was not established; this does not prove release builds can omit the lock. [v0.5 release acceptance](v0.5-release/README.md) separately exercised release discovery with the lock held.

The temporary harness and WSL-only build advice are obsolete. Use the [contributor guide](../../CONTRIBUTING.md#android-cross-builds) for current tooling.
