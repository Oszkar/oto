# P0a - Android debug APK smoke (v0.5 prereq)

Status: **PASS** · Date: 2026-05-30 · Retired the deferred Android criterion from v0.4 acceptance. Archived evidence; the v0.5 design/plan it once accompanied have been retired.

## Goal

Validate that v0.4's full event stack (own SSDP discovery → `sonos-api` SOAP →
GENA subscriptions → `ChangeEvent` stream) actually runs on a real Android device
from a **debug** APK, before S3 (MulticastLock) writes new Android code. Establish
the WSL/Linux/macOS Android cross-build as the supported path.

## Key finding - debug SSDP works WITHOUT a MulticastLock

Discovery succeeded and GENA NOTIFYs were delivered to the on-device callback server
(`0.0.0.0:3400`) **without** any `WifiManager.MulticastLock` held. This confirms the
v0.5 design's premise: the debug build works for incidental reasons (adb keeps the
WiFi radio active), and the lock is a **release-build** requirement. The
P0a-before-S3 ordering holds: S3 must make the *release* APK discover; debug is
already green and must stay green.

## Notes / follow-ups (non-blocking)

- **Flutter 3.44 vs documented 3.38.x.** This run used 3.44.0; `compileSdk`/`targetSdk`/
  `ndkVersion` derive from `flutter.*`, so 3.44 pulled SDK 36 + NDK 28.2.x. Smoke is
  unaffected. Recorded as toolchain drift; a future `just gen` / `flutter analyze`
  under 3.44 may surface lint deltas (FRB codegen is separately pinned at 2.12.0).
- **Kotlin Gradle Plugin deprecation warning** from Flutter 3.44 ("migrate to
  Built-in Kotlin"). Future-Flutter migration; post-1.0 toolchain-polish candidate.
- **NDK install lesson:** install nothing manually - Gradle pulls the exact
  `flutter.ndkVersion` (28.2.13676358) on first build. The pre-installed 26.x was wasted.
