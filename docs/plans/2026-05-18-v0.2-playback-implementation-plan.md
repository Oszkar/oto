# v0.2 Playback Control + State Read — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add identity/group-of-one playback control (play/pause/next/prev, volume, mute) and a one-shot per-speaker state read to oto, proven end-to-end through the Rust↔Dart bridge and verifiable without a LAN.

**Architecture:** Spec — `docs/plans/2026-05-17-v0.2-playback-design.md`. Control via direct low-level SOAP (`sonos_api::SonosClient`), no `SonosSystem` (its topology poll is hardware-proven broken). The `Wire` trait grows with typed methods; playback is addressed by `GroupId` (resolved group-of-one → coordinator → IP inside `oto-wire`), volume/mute/state by `SpeakerId`. Commands are non-sync FRB fns (Dart `Future`) — every command is a blocking SOAP round-trip. Live events stay v0.3.

**Tech Stack:** Rust 2021 (workspace at `native/`), `sonos-sdk =0.5.2` + new `sonos-api =0.5.2` dep, `ureq`, `flutter_rust_bridge =2.12.0`, Flutter + Riverpod 3 codegen, `cargo-nextest`, `cargo-deny`.

```rust
use crate::{
    identifiers::{GroupId, SpeakerId},
    identity::DiscoverySnapshot,
    state::SpeakerState,
    volume::Volume,
};

/// The `Wire` seam. `oto-app` depends on this trait, never on `sonos-sdk`.
///
/// Addressing is the v0.3 seam: playback is per-coordinator, so
/// play/pause/next/previous take a `GroupId`; the impl resolves
/// group-of-one → coordinator → IP. v0.2 resolution is trivial (the
/// group's sole member is its coordinator); v0.3 swaps in real
/// ZoneGroupTopology resolution **without changing these signatures**.
/// volume/mute/state are per-`SpeakerId`. All methods block (SOAP).
pub trait Wire {
    fn discover(&self) -> Result<DiscoverySnapshot, WireError>;

    fn play(&self, group: &GroupId) -> Result<(), WireError>;
    fn pause(&self, group: &GroupId) -> Result<(), WireError>;
    fn next(&self, group: &GroupId) -> Result<(), WireError>;
    fn previous(&self, group: &GroupId) -> Result<(), WireError>;

    fn set_volume(&self, speaker: &SpeakerId, volume: Volume) -> Result<(), WireError>;
    fn set_mute(&self, speaker: &SpeakerId, muted: bool) -> Result<(), WireError>;

    fn speaker_state(&self, speaker: &SpeakerId) -> Result<SpeakerState, WireError>;
}
```

(Keep the existing `WireError` enum, `Display`, `Error` impl, and tests below it; only the imports + trait block change. Remove any now-duplicate `use` lines.)
